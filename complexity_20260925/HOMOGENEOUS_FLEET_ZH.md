**对论文的意义：**
- **单一型号的车队**（同型号家用储能、同型号电动车），台数和初始电量分布都任意，有精确、显式、线性时间的判定（定理 H）。与承诺无关的最优策略是已知的（Evans 2019），定理 H 补上的是“哪些初态能兑现一个区间承诺”的显式刻画。这直接回应“三台是玩具”。

## 1. 命题 5：成比例、同电量百分比的设备可以合成一台

设一组设备 G 的参数成比例：(E_i, C_i, D_i) = α_i (Ē, C̄, D̄)，α_i > 0；初始电量百分比相同：e_i = α_i s̄。把 G 换成一台虚拟设备，参数为 (Σα_i Ē, Σα_i C̄, Σα_i D̄)，初始电量为 Σe_i。

**命题 5.** 对任何承诺，原车队能因果兑现，当且仅当把每组换成虚拟设备后的车队能因果兑现。

**证明.**
- **（⇐）** 虚拟设备在某段功率为 q 时，组内按 α_i/Σα 分配。每台设备的功率和电量约束都是虚拟设备约束乘以 α_i/Σα，所以都满足；组内电量百分比始终相同；分配只用当前信息，是因果的。
- **（⇒）** 原车队的任一因果策略，按组把功率和电量相加，就得到虚拟设备的一个因果策略，约束逐项相加即得。∎

**推论.** 不超过 3 组时，定理 4 精确判定。计时口径：先用 O(设备总数) 次运算把每组参数加起来，之后递推本身是 O(T)；在线执行时，每段把虚拟设备的动作分配回全部设备，还需要 O(设备总数) 次运算。

**说明：**
- 这种合成是常见做法：按容量比例分配以保持电量百分比一致，是常用的控制方法；Evans–Tindemans–Angeli（2110.08549v3 §V-B）给出了剩余可持续时间相同时合成为单台虚拟电池的条件。但他们的框架是“先放电、后回充”两阶段且不交叉充电，所以只能作为背景，不能说双向成比例合成已经由该段证明。新意在于与定理 4 结合后得到的精确结果。
- 去掉“电量百分比相同”后，就不能一般保证精确。反例：两台 E=2、D=1 的设备，电量 (1,1) 时一步能放 2，电量 (0,2) 时一步只能放 1，总电量都是 2。所以电量不同时，虚拟电池一般只是**外包**，可能误判接受。

## 2. 命题 6：同类设备时，拉平电量是通用的最优策略

设 m 台设备参数完全相同。

**引理 6a（最均衡的下一状态）.** 给定当前电量 e 和请求 y，可达的下一状态集合

  X = {x : e − D ≤ x ≤ e + C, Σx = Σe − y}

是“盒子与超平面之交”。设 X 非空（否则不存在使总和正确的 λ）。注水点 x*_i = clip(λ, e_i − D, e_i + C)（λ 使总和正确；λ 在饱和平台上可能不唯一，但向量 x* 唯一）被 X 中每一点优超，记作 x* ≺ x。

证明：设 x ∈ X、x ≠ x*。因为总和相同，必有 i 使 x_i > x*_i、j 使 x_j < x*_j。由 x*_i < x_i ≤ e_i + C 知 x*_i 没有被上界截断，所以 x*_i ≥ λ；同理 x*_j ≤ λ。因此 x_i > x*_i ≥ λ ≥ x*_j > x_j。取 δ = min(x_i − x*_i, x*_j − x_j)，把 x_i 减 δ、x_j 加 δ（Robin Hood 转移）：
- 这一步之后至少有一个坐标等于目标值，并且以后不再改动它；超额坐标始终不低于目标，缺额坐标始终不高于目标，不会越过，也不会离开可达区间。所以至多 m 步到达 x*。
- 每一步都是从较大的值向较小的值转移，所以对任意凸函数 φ，Σφ 不增。
于是对所有凸 φ 有 Σφ(x*) ≤ Σφ(x)，总和又相同；由 Hardy–Littlewood–Pólya 定理，这等价于 x* ≺ x。

X 没有并入物理盒 [0, E] 不影响后面的论证：只要存在 x ∈ X ∩ K_{t+1}，由引理 6b 就有 x* ∈ K_{t+1}，因而 x* 自动在物理盒内。

这是“基多面体有最小优超元”的特例，参见 Tamir 1995、Fujishige 1980 关于字典序最优基的结果，以及 Schoot Uiterkamp 2201.06596。

**引理 6b.** 若 S 是凸集且在坐标置换下不变，x ∈ S 且 z ≺ x，则 z ∈ S。

证明：z ≺ x 意味着 z = Px，其中 P 是双随机矩阵（Hardy–Littlewood–Pólya）。由 Birkhoff 定理，P 是置换矩阵的凸组合，所以 z 是 x 的若干置换的凸组合，因而在 S 中。

**命题 6.** 设备全同时，每个 K_t 关于置换不变且是凸集。策略“每段走到注水点 x*”对任何承诺都最优：只要有某个因果策略能兑现，它也能。

证明：
- **K_t 的性质：** 设备相同，所以递推算子与置换交换，K_t 关于置换不变；K_t 是凸集。
- **归纳：** 若 e ∈ K_t，对当前请求 y（由端点引理，区间内任意 y 都可以），X ∩ K_{t+1} 非空，取其中一点 x。由引理 6a，x* ≺ x；由引理 6b，x* ∈ K_{t+1}。∎

**推论（多类型车队）.** K_t 在**同类设备之间**置换不变。给定每类设备这一段的总功率，同类设备内部走注水点不会有任何损失。论证是切片：固定其他类型的坐标，K_{t+1} 在该类坐标上的切片是凸集，并且在同类置换下不变；对这个切片用引理 6a、6b 即可。所以多类型车队里，真正需要决策的只是功率在各类之间怎么分。

**与 S1 的关系：** S1 说异构双向时不存在与承诺无关的最优规则，命题 6 说同类时存在。两者互补。

**已有结果（10-07 文献核对发现，10-09 复核核对原文）：** Evans 2019 博士论文（Imperial，第 8 章）已经证明了更一般的版本。条件 (8.5) 是：无损（η_i = 1）；充电额定功率与放电额定功率成比例（r_i = αq_i）；最大剩余可持续时间相同。在放电功率为正的归一化下，就是 E_i/D_i 相同、C_i/D_i 相同，也就是设备彼此成比例。在此条件下，允许任意符号的请求和设备间交叉充电，“拉平剩余可持续时间”的策略使可行请求集合在每个时刻都最大（定理 8.3.4；离散时间版本见推论 8.3.13），离散时间形式为 z_i = min(max(x_i − Δt, ẑ), x_i + αΔt)（引理 8.3.10 的式 (8.12)）。对完全同参数的设备，取 x_i = e_i/D、α = C/D 换回能量单位，就是我们的注水点。零功率的情形不能直接套用这些比值，但我们的优超证明覆盖它们。所以命题 6 的主体**不是新结果**，引理 6a、6b 的优超证明只是另一种证法。多类型车队里“同类内部拉平不会有损失”这条推论，Evans 的论文没有单独写出（他要求整个车队成比例）。

**一个注记（连接已知结果）：** 存在通用最优策略时，从 e 出发能因果兑现区间承诺，当且仅当盒内每一条请求序列都能逐路径兑现。理由是：若某条序列能被某条轨迹兑现，通用策略在每个时刻的可行集合都不小于那条轨迹的，所以它也能兑现这条序列。因此同类车队的 K_t 是一族逐路径可行集合的交。

但“一族集合的交”本身推不出面的方向：还需要每条固定序列的可行初态集合有子集描述，这里没有证明。同类车队 K_t 只有子集面这一点，目前的依据是定理 H（作为它的推论），不是这个注记。

## 3. 定理 H：单一类型、任意台数的精确递推

**记号：** 对向量 e，top_k(e) 是最大 k 个分量之和，bottom_k(e) 是最小 k 个分量之和。

**定理 H.** 设 m 台无损设备参数相同（E, C, D 有限非负），请求区间 l_t ≤ u_t。则每个非空的 K_t 都可以写成

  K_t = {e : top_k(e) ≤ b_k 且 bottom_k(e) ≥ a_k，k = 1..m}，

其中 b 关于 k 凹，a 关于 k 凸，b_0 = a_0 = 0。这 2m 个数由下面的递推精确给出，只用 +、−、min、max：

1. **终端：** b_k = Ek，a_k = 0。
2. **判空：** 若 l < −Cm 或 u > Dm，或者下一集合为空，则为空。
3. **单请求界：**
   - b̃_k = b_k + min(Dk, l + C(m−k))
   - ã_k = a_k + max(−Ck, u − D(m−k))
4. **物理盒：**
   - b̂_k = min(Ek, b̃_k)
   - â_k = max(0, ã_k)
5. **判非空：** 非空当且仅当 â_m ≤ b̂_m。
6. **紧化：**
   - b_k ← min(b̂_k, b̂_m − â_{m−k})
   - a_k ← max(â_k, â_m − b̂_{m−k})

第 6 步的两条赋值必须同时读取**旧的** b̂、â，不能把前一条已经更新的数组用于后一条。

**复杂度：**
- **算术次数：** 每段 O(m)，总共 O(mT)。这里 m 是显式给出的设备数（实例里列出 m 个初态坐标）；如果 m 只以二进制计数给出，O(mT) 不能写成关于 log m 的多项式。
- **判定初态：** 把 e 排序一次，构造前缀和，再核对 2m 个不等式，O(m log m)。
- **不需要除法：** 只针对界的递推。常数 Ek、Dk、C(m−k) 可以用 O(m) 次累加预先算好。实现注水策略时求 λ 会用到除法。
- **位复杂度（有理数输入）：** 设输入分母的最小公倍数为 L。只用加、减、比较和选取，所有界都在 (1/L)ℤ 中，log L 不超过全部输入分母的位数之和。非空的紧界是物理盒内的子集极值，所以 0 ≤ a_k ≤ b_k ≤ mE；未紧化的中间量的绝对值不超过 O(m(E+C+D) + max_t(|l_t| + |u_t|))。判空后递推停止。因此每个数的位数有多项式界，总位操作数是输入长度的多项式。
- **实现：** `evidence/homogeneous_exact.py` 的 `step()` 直接用第 4 步的两项公式，每段 O(m)；完整卷积 O(m²) 只在开启 CROSSCHECK 的验证中计算。实测（精确有理数，20 段）：m = 100、1,000、10,000、100,000 时分别约 0.02、0.18、1.9、19 秒，随 m 线性增长；m = 100,000 时成员判定约 0.37 秒。

### 3.1 引理 S（对称描述的紧界）

设 b(S) = b_{|S|}，其中 b 凹；a(S) = a_{|S|}，其中 a 凸；b_0 = a_0 = 0。令 K = {x : a(S) ≤ x(S) ≤ b(S) ∀S}。则：
- K 非空当且仅当 a_m ≤ b_m；
- 紧界为 β_k = min(b_k, b_m − a_{m−k})，α_k = max(a_k, a_m − b_{m−k})；
- β 关于 k 凹，α 关于 k 凸。

**证明.**
1. **只看排序后的部分和。** 把 x 从大到小排序，令 s_j = top_j(x)。s 是 j 的凹序列，s_0 = 0；反过来，任何这样的凹序列都对应一个排好序的向量。
   - b 只依赖 |S|，所以“x(S) ≤ b_{|S|} 对所有 S”等价于 s_j ≤ b_j。
   - “x(S) ≥ a_{|S|}”等价于 bottom_j(x) = s_m − s_{m−j} ≥ a_j，即 s_i ≤ s_m − a_{m−i}。
2. **固定总量。** 固定 s_m = σ，令 c_j(σ) = min(b_j, σ − a_{m−j})。
   - 两项都是 j 的凹函数：b 凹；a 凸，所以 −a_{m−j} 关于 j 凹。因此 c(σ) 是凹序列。
   - 当 a_m ≤ σ ≤ b_m 时，c_0 = 0、c_m = σ，所以 c(σ) 本身可行，并且逐点不小于任何可行的 s。
3. **取端点。** K 非空当且仅当 [a_m, b_m] 非空。
   - β_k = max_σ c_k(σ) = min(b_k, b_m − a_{m−k})，在 σ = b_m 处取到。
   - α_k = min_σ [σ − c_{m−k}(σ)] = max(a_k, a_m − b_{m−k})，在 σ = a_m 处取到。
4. **凹凸性。** β 是两个凹序列的最小值，所以凹：对内部的 j，取在 j 处实现最小值的那条序列 f，则 β_{j−1} + β_{j+1} ≤ f_{j−1} + f_{j+1} ≤ 2f_j = 2β_j。α 用反向不等式同理是凸的。端点 j = 0、m 不需要二阶差分，但要保留归一化值 β_0 = α_0 = 0。

另外，b 凹、a 凸且 b_0 = a_0 = 0 时，a_m ≤ b_m 推出对所有 k 有 a_k ≤ (k/m)a_m ≤ (k/m)b_m ≤ b_k，与三明治定理给出的非空条件一致。∎

**文献注（10-12）：** 闭式 min(b_k, b_m − a_{m−k}) 与 Frank–Tardos 1988 命题 II.2.10 的形式相同：g-polymatroid 与“板” α ≤ x(S) ≤ β 相交后，上界为 min(b(X), β − p(S∖X))。区别在于，他们要求上下界满足交叉条件（g-polymatroid），引理 S 不要求，靠的是对称性和凹凸性。

### 3.2 定理 2 的对称版本：任意台数

**命题 H2.** 设 K 非空，K 恰好等于它的子集紧界描述，这些紧界关于置换不变且 b 凹、a 凸（即 K 属于 H3″ 且置换不变）；设 −mC ≤ y ≤ mD，使 P_y 非空。则对任意 m，K+P_y 等于它的子集外包，紧界是 b + b_P、a + a_P。

这里用到一个事实：对称集函数 φ(|S|) 子模，当且仅当 φ 在 0..m 上凹（加入一个元素的边际增量是 φ_{k+1} − φ_k，边际递减就是凹性）。

证明：沿用定理 2 的证明，只有一处不同。定理 2 唯一用到 N≤3 的地方是“混号约束 (★) 中的 M 只能取 ∅ 或 R₀”。设备相同时，(★) 右端的 b(A∪M) − a(B∪M) = b_{|A|+j} − a_{|B|+j} 只依赖 j = |M|，而且是 j 的凹函数（b 凹，−a 凹）。所以它在 j ∈ [0, |R₀|] 上的最小值在两端取到。于是每个中间的 M 都被 M = ∅ 或 M = R₀ 的约束蕴含，而这两者被子集外包蕴含（定理 2 对 g(∅)、g(R₀) 的论证对任意 N 成立）。A 或 B 为空的情形与定理 2 相同。∎

### 3.3 定理 H 的证明

对 t 反向归纳。设 K := K_{t+1} 非空，由 (a, b) 描述，b 凹、a 凸。

1. **单请求。** 由命题 H2，K+P_y 的紧界是 b + b_{P_y}、a + a_{P_y}。其中 b_{P_y}(k) = min(Dk, y + C(m−k)) 是两个线性函数的最小值，凹。两个端点取交时，上界取 l 端点、下界取 u 端点（单调性）。所以 b̃ 凹、ã 凸。
2. **物理盒。** 并入物理盒用卷积（F3）：b̂_k = min_{j≤k}[b̃_j + E(k−j)] = Ek + min_{j≤k} g(j)，其中 g(j) = b̃_j − Ej 是凹的。凹函数在区间上的最小值在端点取到，又 g(0) = 0，所以 b̂_k = min(Ek, b̃_k)，仍凹。â 同理，仍凸。
3. **判空与紧化。** 由引理 S 判空并紧化，结果仍是凹/凸的，进入下一步归纳。
4. **终端。** K_T 的界 b_k = Ek、a_k = 0 满足条件。∎

## 4. 例 C：3 类设备、电量不同时，子集界不精确

**参数：** E = (4, 4, 1, 1)，C = (0, 0, 3, ½)，D = (1, 1, 2, 0)。设备 1、2 完全相同，所以只有 3 类设备。T = 2，承诺依次为 [1/5, 3/5]、[−1, 8/5]。

**手工推导：**
1. **t=1，y = −1：** 设备 1、2 不能充电，所以设备 3、4 至少净吸收 1，得 e₃ + e₄ ≤ 2 − 1 = 1。
2. **t=1，y = 8/5：** 设备 1、4 最多共放 1 + 0 = 1，所以设备 2、3 至少要放 3/5，得 e₂ + e₃ ≥ 3/5。
3. **t=1 的差：** 两式相减，K₁ 上 e₄ − e₂ ≤ 2/5。
4. **推回 t=0：** 第一步中 p₄ ≤ D₄ = 0，p₂ ≥ −C₂ = 0，所以 e₄ − e₂ 不会减小。K₀ 上 e₄ − e₂ ≤ 2/5。
5. **外包里的点：** 子集外包包含 e* = (19/10, 1/10, 1/5, 1)，其中 e₄ − e₂ = 9/10。

**精确证书：** `evidence/n4_real_certificate.py --three-types`。30 个子集方向的有理数树策略逐一精确验证，第 4 步的不等式被 e* 违反。

**不是零功率的退化现象：** 把零功率改成 1/100 仍然失败（47/50 对 9/20），同样有精确证书。

**意义：**
- 例 B 的机制只需要 3 类设备就能出现：同类设备一台电量多、一台电量少，而外包把它们混在一起。
- 命题 5 在同类电量百分比相同时保证精确合成；电量状态不同时，这一保证一般失效。例 C 就是一个失效的实例。
- 单一类型时不会出现：只有一类设备时，混号约束关于 |M| 是凹的，定理 H 保证精确。
