## 1. 记号与已知工具

- V = {1,…,N}；对向量 x 和子集 S，记 x(S) = Σ_{i∈S} x_i。
- P_y = {p : −C ≤ p ≤ D, p(V) = y}。
- P(b) = {x : x(S) ≤ b(S), ∀S}，Q(a) = {x : x(S) ≥ a(S), ∀S}。
- 所有集函数都满足 f(∅) = 0。
- 模型参数：E、C、D 有限且非负；每个请求区间非空（l_t ≤ u_t）；时段长度 Δ = 1。定理本身对实数参数成立，有理数编码只在讨论位复杂度时用到（§5）。

**类 𝓗：** 形如 K = P(b) ∩ Q(a) 的集合，其中 b 子模、a 超模。这里的 (a,b) 只是一个“描述”，不要求是紧界。

**类 H3″：** K 非空，K 恰好等于它的子集紧界描述 {a_K ≤ x(S) ≤ b_K}，并且紧界 b_K 子模、a_K 超模，其中 b_K(S) = max_K x(S)，a_K(S) = min_K x(S)。显然 H3″ ⊆ 𝓗。

**F1（支撑函数可加）：** b_{K+P}(S) = b_K(S) + b_P(S)，a 同理。

**F2（单请求公式，原载于已归档的 `H3PP_OPERATOR_PROGRESS_ZH.md` §2）：** 设 −C(V) ≤ y ≤ D(V)，则

  b_{P_y}(S) = min{D(S), y + C(V∖S)}，a_{P_y}(S) = max{−C(S), y − D(V∖S)}。

证明：p(S) 的可行范围是 [−C(S), D(S)] 与 [y − D(V∖S), y + C(V∖S)] 这两个区间的交，端点都能用连续分配达到。

令 w = C + D，则 b_{P_y}(S) = −C(S) + min{w(S), y + C(V)}：模函数加上一个非负模函数的常数截断，所以子模。a_{P_y} 同理超模。两者都随 y 单调不减。

**F3（向量卷积）：** 设 b 子模，c 是向量，令 (b□c)(S) = min_{T⊆S} [b(T) + c(S∖T)]。则 b□c 子模，并且 P(b) ∩ {x ≤ c} = P(b□c)。（出处：Frank–Tardos 1988 命题 II.2.11 给出 g-polymatroid 与盒子之交的公式 min_Y [b(Y) + g(X∖Y) − f(Y∖X)]，取下界 f = −∞ 即为此式；子模多面体是 g-polymatroid（同文命题 II.2.1）。）

证明：
- **集合相等：** “⊆”由 x(S) = x(T) + x(S∖T) 得到。“⊇”分别取 T = S 和 S = {i}、T = ∅。
- **子模：** 取 X、Y 各自的最优 X′ ⊆ X、Y′ ⊆ Y。由 b 子模，b(X′) + b(Y′) ≥ b(X′∪Y′) + b(X′∩Y′)。再逐元素验证 1_{X∖X′} + 1_{Y∖Y′} = 1_{(X∪Y)∖(X′∪Y′)} + 1_{(X∩Y)∖(X′∩Y′)}（两边都等于 x + y − x′ − y′，这里用了 max 加 min 等于和）。
- **对偶版本：** (a♯c)(S) = max_{U⊆S} [a(U) + c(S∖U)] 超模，且 Q(a) ∩ {x ≥ c} = Q(a♯c)。
- **只改 V 处的值：** 只降低 b(V)（或只升高 a(V)）不破坏子模（超模），因为 V 只出现在非平凡不等式的右端。

**F4（Frank 离散三明治定理）：** 若 b 子模、a 超模、a ≤ b（归一化到空集取 0），则存在 x ∈ ℝ^V 使 a(S) ≤ x(S) ≤ b(S) 对所有 S 成立；整数输入时 x 还可以取整数。本证明只用到实值版本，不需要 g-polymatroid 的交叉条件。推论：对类 𝓗 的描述，K ≠ ∅ 当且仅当 a ≤ b 逐点成立。

出处：
- 原始文献：A. Frank, An algorithm for submodular functions on graphs, *Annals of Discrete Mathematics* 16 (1982), 97–120, DOI 10.1016/S0304-0208(08)72446-0。出版社摘要写的是整数版本；我们和复核都没有读到原文全文，所以不引用原文的定理编号。
- 实值版本的公式：据复核核对，见 K. Murota, *Discrete Convex Analysis II* 讲义（2016），第 38 张幻灯片。
- 正式出版的表述（10-12 核对原文）：
  - **实数版：** A. Frank, É. Tardos, Generalized polymatroids and submodular flows, *Math. Program.* 42 (1988) 489–563，定理 I.2（引 Frank 1982）。原文对相交子模/超模的实值函数 b'、p' 给出：存在模函数 m 使 p' ≤ m ≤ b'，当且仅当对任意两族不交子集 {F_i}、{G_j}（并集相同）有 Σp'(F_i) ≤ Σb'(G_j)；整数输入时 m 可取整数。完全子模/超模时，这个条件化为 p' ≤ b'，就是 F4。
  - **整数版：** K. Murota, Discrete convex analysis, *Math. Program.* 83 (1998) 313–371，定理 3.5；注 3.1 指出它与 Edmonds 交定理等价。

**F5（紧界的弱交换）：** 对任何非空紧集 K 的紧界，以及不交的 X、Z：
- b_K(X∪Z) ≥ b_K(X) + a_K(Z)：取 x* ∈ K 使 x*(X) = b_K(X)，则 b_K(X∪Z) ≥ x*(X) + x*(Z) ≥ b_K(X) + a_K(Z)。
- a_K(X∪Z) ≤ a_K(X) + b_K(Z)：同理。

## 2. 命题 1（任意 N）：单请求前驱的精确 H-表示

**命题 1.** 设 K = P(b) ∩ Q(a) ≠ ∅，b 子模，a 超模（不要求紧），P_y ≠ ∅。则 e ∈ K+P_y 当且仅当下面三组条件同时成立：

- (ii) 对所有 T：e(T) ≤ b(T) + y + C(V∖T)；
- (iii) 对所有 U：e(U) ≥ a(U) + y − D(V∖U)；
- (i) 对所有两两不交的 A、B、M：**e(A) − e(B) ≤ b(A∪M) − a(B∪M) + D(A) + C(B)**。

其中 A、B 可以为空。因此 K+P_y 有一个约束法向量都取自 {0,±1}ᴺ 的 H-表示；特别地，它每个 facet 的法方向都可以取成 {0,±1}ᴺ 中的向量（集合低维时，指仿射包内的相对 facet）。

**证明.**
1. **改写成找 x。** e = x + p 当且仅当 x = e − p。令 u = e + C，l = e − D，β = e(V) − y，则 e ∈ K+P_y 当且仅当存在 x 满足：x ∈ P(b)，x ∈ Q(a)，l ≤ x ≤ u，x(V) = β。
2. **上侧合并。** 由 F3，P(b) ∩ {x ≤ u} ∩ {x(V) ≤ β} = P(b″)，其中 b″ = b□u，再把 V 处的值降为 min{β, (b□u)(V)}。b″ 子模。
3. **下侧合并。** 同理，Q(a) ∩ {x ≥ l} ∩ {x(V) ≥ β} = Q(a″)，a″ 超模。
4. **判非空。** 由 F4，所需的 x 存在当且仅当 a″(S) ≤ b″(S) 对所有 S 成立。
5. **展开。** 对 T、U ⊆ S，逐项展开 a(U) + l(S∖U) ≤ b(T) + u(S∖T)。令 A = T∖U、B = U∖T、M = T∩U、R = S∖(T∪U)，得到

   e(A) − e(B) ≤ b(A∪M) − a(B∪M) + D(A) + C(B) + w(R)，其中 w = C + D ≥ 0。

   R = ∅ 时最紧，这就是 (i)。
6. **V 处的附加条件。** S = V 时还要比较 β 与 b□u、a♯l，分别给出 (ii) 和 (iii)。∎

(i) 对所有 e ∈ K+P_y 显然有效：e(A) − e(B) = x(A∪M) − x(B∪M) + p(A) − p(B)。命题 1 说的是这些条件合起来也是充分的。

**数值核对：** `evidence/single_request_description_check.py`。N=3、4 各 150 个随机描述（不要求紧），每个 20 个随机方向；上述 H-表示的支撑函数与 h_K + h_{P_y} 的最大差分别是 3.6e−15 和 7.1e−15。

## 3. 定理 2（N≤3）：单请求步骤保持 H3″

**定理 2.** 设 N ≤ 3，K ∈ H3″，紧界为 (a,b)，P_y ≠ ∅。则

  K+P_y = Õ := {e : a(S) + a_{P_y}(S) ≤ e(S) ≤ b(S) + b_{P_y}(S)}。

它的紧界 b+b_P 子模、a+a_P 超模，所以 K+P_y ∈ H3″。

**证明.** 由 F1，K+P_y ⊆ Õ。下面证明 Õ 中的任意 e 满足命题 1 的三组条件。

- **(ii)、(iii)：** 由 b_{P_y}(T) ≤ y + C(V∖T) 和 a_{P_y}(U) ≥ y − D(V∖U) 直接得到。

- **(i)，B = ∅：** 要证 e(A) ≤ b(A∪M) − a(M) + D(A)。由 e ∈ Õ 得 e(A) ≤ b(A) + D(A)；由 F5 得 b(A) ≤ b(A∪M) − a(M)。
- **(i)，A = ∅：** 对称，用 a(B∪M) ≤ a(B) + b(M)。
- **(i)，A = B = ∅：** 就是 a(M) ≤ b(M)。

- **(i)，A、B 都非空，关键情形。** 令 R₀ = V∖(A∪B)。对任意 N₀ ⊆ R₀，e(A) − e(B) = e(A∪N₀) − e(B∪N₀)。用 Õ 的上下界得到

  e(A) − e(B) ≤ b(A∪N₀) − a(B∪N₀) + D(A) + C(B) + g(N₀)，

  其中 s = y + C(B) − D(A)，Ṅ = R₀∖N₀，

  g(N₀) = min{D(N₀), s + C(Ṅ)} + min{C(N₀), D(Ṅ) − s}。

  代入 F2 逐项验证：
  - g(∅) = min{0, s + C(R₀)} + min{0, D(R₀) − s} ≤ 0；
  - g(R₀) = min{D(R₀), s} + min{C(R₀), −s} ≤ s + (−s) = 0。

  因此 M = ∅ 和 M = R₀ 时，(i) 被 Õ 蕴含（取 N₀ = M）。**N ≤ 3 时 A、B 非空意味着 |R₀| ≤ 1，M 只能是 ∅ 或 R₀。**

- **紧界。** Õ 的界就是 K+P_y 的紧界（F1），而它们子模/超模（F2）。∎

**N ≥ 4 时的缺口正好在这里：** 当 ∅ ≠ M ⊊ R₀ 时，g(M) 可以为正，此时 (i) 不被 Õ 蕴含。例 A 就是这种情形。

## 4. 引理 3：描述的紧界（N=3 时仍子模/超模）

设 K = P(b) ∩ Q(a) ≠ ∅，b 子模，a 超模。记 β(S) = max_K x(S)，α(S) = min_K x(S)。

**(a) 单点（任意 N）：** β(i) = min_{S∋i} [b(S) − a(S∖i)]；α(i) = max_{S∋i} [a(S) − b(S∖i)]。

证明：
1. **加约束。** 令 a′(X) = a(X)（i ∉ X），a′(X) = max{a(X), θ + a(X∖i)}（i ∈ X）。可以验证 K ∩ {x_i ≥ θ} = P(b) ∩ Q(a′)。
2. **a′ 超模。** 记 U = X∪Y，I = X∩Y。左端 a′(X) + a′(Y) 中每个 max 取哪一支，都要给出右端相应的下界：

   | 情形 | 左端所取的分支 | 右端用到的下界 | 所用的超模不等式 |
   |---|---|---|---|
   | X、Y 都不含 i | a(X) + a(Y) | a′ = a | a 在 (X, Y) 上 |
   | 只有 X 含 i | a(X) + a(Y) | a′(U) ≥ a(U)，a′(I) = a(I) | a 在 (X, Y) 上 |
   | 只有 X 含 i | θ + a(X∖i) + a(Y) | a′(U) ≥ θ + a(U∖i)，a′(I) = a(I) | a 在 (X∖i, Y) 上；因为 i ∉ Y，(X∖i)∪Y = U∖i，(X∖i)∩Y = I |
   | X、Y 都含 i | a(X) + a(Y) | a′(U) ≥ a(U)，a′(I) ≥ a(I) | a 在 (X, Y) 上 |
   | X、Y 都含 i | 2θ + a(X∖i) + a(Y∖i) | a′(U) ≥ θ + a(U∖i)，a′(I) ≥ θ + a(I∖i) | a 在 (X∖i, Y∖i) 上 |
   | X、Y 都含 i | a(X) + θ + a(Y∖i) | a′(U) ≥ a(U)，a′(I) ≥ θ + a(I∖i) | a 在 (X, Y∖i) 上；因为 i ∈ X，X∪(Y∖i) = U，X∩(Y∖i) = I∖i |
   | X、Y 都含 i | θ + a(X∖i) + a(Y) | 上一行的镜像 | a 在 (X∖i, Y) 上 |

   所以“取 max”本身并不自动保持超模，这里靠的是每一种分支组合都能配上一条原来的超模不等式。
3. **判非空。** 由 F4，非空当且仅当 a′ ≤ b，也就是 θ ≤ b(S) − a(S∖i) 对所有 S ∋ i 成立。K 有界闭，所以最大值在这个阈值处取到。α(i) 用对称论证（对 −K）。
4. **为什么不能直接把 i 换成二元集。** 复核给出的最小反例：V = {1,2,3}，a(X) = 1[{1,3} ⊆ X]，b(X) = 3|X|，对 I₀ = {1,2} 做同样的构造，取 θ = 1，得到 a′(12) + a′(13) = 2 > 1 = a′(123) + a′(1)，超模性失败。所以二元集要用下面 (c) 的切片论证。

**(b) 全集（任意 N）：** β(V) = b(V)，α(V) = a(V)。证明：把 a(V) 升到 θ ≤ b(V)（F3 最后一条），再用 F4。

**(c) 二元集（N=3，{i,j,k} = V）：** β(ij) = min{b_ij, b_V − a_k, b_V + b_i − a_ik, b_V + b_j − a_jk}。α 取镜像：min 换成 max，a、b 的角色互换。

证明：
1. **切片。** 在 x_k = t 处切片，得到 (x_i, x_j) 的二维六界集合：
   - 上界：u_i(t) = min{b_i, b_ik − t}，u_j(t) = min{b_j, b_jk − t}，u_ij(t) = min{b_ij, b_V − t}；
   - 下界：ℓ_i(t) = max{a_i, a_ik − t}，ℓ_j(t) = max{a_j, a_jk − t}，ℓ_ij(t) = max{a_ij, a_V − t}；
   - t 本身还要满足 a_k ≤ t ≤ b_k。
   - K 在 x_k 轴上的投影是紧凸集的投影，所以恰好是闭区间 [α(k), β(k)]，两个端点都可行；切片非空当且仅当 t 在这个区间内。二维六界集合不需要有内点，单点或线段切片也适用 SEED §2。
2. **二维结论。** 由 `SEED_N2_THEOREM_ZH.md` §2，非空切片上 x_i + x_j 的最大值是 min{u_ij, u_i + u_j}。它关于 t 不增，所以
   β(ij) = min{b_ij, b_V − α(k), u_i(α(k)) + u_j(α(k))}。
3. **代入 (a) 的 α(k)。** α(k) = max{a_k, a_ik − b_i, a_jk − b_j, a_V − b_ij}，所以 b_V − α(k) 恰好给出三项 b_V − a_k、b_V + b_i − a_ik、b_V + b_j − a_jk，另有一项 b_V − a_V + b_ij ≥ b_ij 被 b_ij 支配。
4. **剩下一项被支配。** u_i + u_j 展开后的四种组合都被支配：
   - b_i + b_j ≥ b_ij；
   - b_i + b_jk − α(k) ≥ b_V − α(k)；
   - b_ik + b_j − α(k) ≥ b_V − α(k)；
   - b_ik + b_jk − 2α(k) ≥ b_V + b_k − 2α(k) ≥ b_V − α(k)，这里用了 b_k ≥ β(k) ≥ α(k)。

**(d) 子模性（N=3）：** 在 2^V 中，不可比较的集合对只有三类：两个单点、单点与另外两点组成的二元集、共享一个元素的两个二元集。前两类不交，β(X) + β(Y) ≥ β(X∪Y) 显然成立。只需证明

  **β(ij) + β(ik) ≥ β(V) + β(i)。**

以 i=1、j=2、k=3 为例。β(12) 取 (c) 的四项 P₁..P₄，β(13) 取对应的四项 Q₁..Q₄，β(V) = b123。只需对 16 个组合验证 P_m + Q_n − b123 ≥ β(1) = min{b1, b12−a2, b13−a3, b123−a23}。每一行只用子模、超模和 a ≤ b：

| (b123+b2−a23, b123+b3−a23) | b123+b2+b3−2a23 | b123−a23 | b2+b3≥b23≥a23 |

其他标号由对称性得到。α 的超模性：对 −K 应用同一结论，−K 的描述 (−b, −a) 仍属于 𝓗。∎

**精确证书（独立于上面的人工证明）：** `evidence/n3_lemma_certificate.py`。
- 精确枚举 LP 对偶多面体 D_S 的全部顶点：N=3 时每个 S 有 9 或 11 个。
- 用有理数 Farkas 恒等式验证三件事：闭式与全部对偶顶点一致；分数对偶顶点被整数顶点支配；T2 的 121 个顶点对全部成立。
- 用同一脚本跑 N=4，21,616/50,176 个顶点对无法认证。注意 N=4 时脚本右端用的仍是 b({1,2,3})，它不等于 β({1,2,3})，所以检验的是比子模性更强的不等式。这个数字只说明检验不是空洞的，**不是**子模性反例的个数；无法认证本身也不构成反例。

**N=4 不成立的迹象：** `evidence/classH_tight_probe.py` 的“割型”生成器在 N=4 时有 79/255 个描述的紧界违反子模性；N=3 时 657 例无违反。这是浮点证据。

**推论（不需要除法）：** 分数对偶顶点总被整数顶点支配，所以紧界总是 a、b 的整数系数组合。

## 5. 定理 4（N≤3 精确递推）

**定理 4.** 设 N ≤ 3，模型无损、全程可用；E、C、D 有限且非负，允许 C≠D、零容量、零功率等退化情形；每个请求区间满足 l_t ≤ u_t。则每个 K_t 或为空，或属于 H3″，并由下面的递推精确给出：

1. **终端：** K_T 的紧界为 (0, E(S))。
2. **判空：** 若 K_{t+1} = ∅，或 l_t < −C(V)，或 u_t > D(V)，则 K_t = ∅。
3. **加单请求界：** b̃ = b_{t+1} + b_{P_{l_t}}，ã = a_{t+1} + a_{P_{u_t}}。上界取 l 端点、下界取 u 端点，这是 F2 的单调性。
4. **并入物理盒：** b̂ = b̃□E，â = ã♯0（F3），两者仍子模/超模。
5. **判非空：** K_t ≠ ∅ 当且仅当 â ≤ b̂（F4）。
6. **紧化：** 用引理 3 的闭式计算紧界 (a_t, b_t)。

**证明.** 对 t 反向归纳。设 K := K_{t+1} ∈ H3″。
- 由端点引理，K_t = [0,E] ∩ (K+P_l) ∩ (K+P_u)。
- 由定理 2，K+P_y = {a + a_{P_y} ≤ e(S) ≤ b + b_{P_y}}。两个端点取交时，由单调性，上界由 l 端点给出、下界由 u 端点给出。
- 并入盒约束后得到类 𝓗 的描述 (â, b̂)。由 F4 判非空；由引理 3，紧界子模/超模，而 K_t 是子集约束的交，等于它的紧界描述，所以 K_t ∈ H3″。∎

N=2 是其中的特例，与 `SEED_N2_THEOREM_ZH.md` 的六界公式一致。N=1、2 也可以通过加入 E=C=D=0 的惰性设备嵌入 N=3 的情形；T=0 时只有终端盒。

**复杂度。** 定理本身对实数参数成立。下面的位复杂度只针对有理数输入：按二进制编码，T 个区间逐一列出。

- **算术次数：** 每段是固定次数的 +、−、比较、min、max。单请求界共 14 个；盒卷积每个界至多 8 个候选项（S = V 时有 2³ 个）；紧化公式每个界至多 4 项。所以算术次数是 O(T)。
- **分母：** 令 L 为全部输入分母的最小公倍数。每次 min 或 max 只是选中一个已有的表达式，所以在所选的分支上，每个输出都是输入 E、C、D、l、u 的整数线性组合。这个组合随分支变化，并不是对所有输入统一的一个线性表达式。因此所有数的分母都整除 L。
- **大小：** 令 R = 1 + E(V) + C(V) + D(V) + max_t(|l_t| + |u_t|)，T = 0 时最后一项取 0。每段输入的紧界落在 [0, E(V)] 内。单请求界、卷积候选项、紧化候选项都是固定个数的紧界与功率、请求值相加减，绝对值不超过 cR，其中常数 c 只依赖 N ≤ 3。每段都重新紧化，所以不会把不受物理盒控制的量一路累加下去。
- **结论：** 乘以 L 以后，每个数是位数为 O(1 + log L + log R) 的整数，而 log L 和 log R 都不超过输入长度。所以总位复杂度是输入长度的多项式。

**因果策略：** 在 e ∈ K_t 观察到 y 后，要在 K_{t+1} ∩ [e−D, e+C] ∩ {x(V) = e(V)−y} 中找一点 x，取 p = e − x。由定理 2，这个集合非空。实现上可以：
- 先用 F3 把 [e−D, e+C] 并入 K_{t+1} 的上下界，再把总量 x(V) = e(V) − y 并入全集处的上下界（同命题 1 第 2、3 步），得到合法的子模/超模描述；然后取 x_1 为该集合上 x_1 的最大值（引理 3(a)），再在剩下的二维六界集合上用 `SEED_N2_THEOREM_ZH.md` §5 的选择器。合并这一步不能省：只改单点的值，不一定保持子模/超模；
- 或者直接用 `n3_exact.action()` 的有理数顶点枚举。

**实现与核对：** `evidence/n3_exact.py` 的 `step()` 已改为上面的递推。在 `CROSSCHECK` 开启时：
- 每一步再用 14 个不等式的精确顶点枚举独立紧化一次，要求结果完全相同；
- 同时 assert 输出属于 H3″。

本轮运行结果：
- `n3_exact.py` 自带 validate：46 例（43 非空、3 空），602 次支撑界与树 LP 对照（浮点），94 次有理数动作回放（每段取区间中点请求），全部通过。
- `review_stress.py` 种子 3、4：结果见 `SUMMARY_REPORT_20260928_ZH.md` §3。
- 复核时种子 5 报出一次“外包顶点不可行”。经完整的有理数因果策略核对，那个点是可行的，是默认 HiGHS（带 presolve）给出的假不可行，不是数学反例（复核 §7.6）。`review_stress.py` 现在对这类浮点分歧先关闭 presolve 重解，单独记为 `solver_false_infeasible`，并把这个案例作为回归检查。
- 复核的独立攻击（`review_codex_independent.py`，不导入本仓库的求解代码）：60 个极端 N=3 实例（T = 5–6），50 个非空实例的 461 个外包顶点全部有精确策略见证，1,300 次子集与混号方向的支撑值都有有理数原始—对偶最优性证书，0 次失败；160 个不紧的描述上，闭式紧化与精确顶点枚举一致。

## 6. N=4 反例

### 6.1 例 A（第一层，合成集合）

K = {x ∈ [0,10]⁴ : x₁+x₃ ≤ 10, x₂+x₃ ≥ 10}，C = D = 1，y = 0。

- **K ∈ H3″：** 紧界 b(S) = 10|S| − 10·[{1,3}⊆S]（模函数减去一个与函数，子模），a(S) = 10·[{2,3}⊆S]（超模）。有 3 处交叉不等式失败，所以 K 不是 g-polymatroid。
- **点 e = (7,3,5,5)：** 它精确满足 Õ 的全部 30 个子集约束，但 e₁ − e₂ = 4。
- **有效不等式：** 在 K+P₀ 上，e₁ − e₂ = [(x₁+x₃) − (x₂+x₃)] + (p₁ − p₂) ≤ 0 + 2。所以 e ∉ K+P₀。
- **加物理盒：** 与 [0,10]⁴ 取交（完整算子，l = u = 0）后，输出上 max(e₁−e₂) = 2，而它的紧子集外包上是 4。
- **对应到定理 2 的证明：** A = {1}，B = {2}，M = {3}，R₀ = {3,4}，M 是 R₀ 的真子集，g(M) = 2。

脚本：`evidence/n4_single_request_cx.py`。

### 6.2 例 B（第三层，真实递推）

**参数：** E = (4,5,1,1)，C = (0,0,3,½)，D = (1,½,2,0)，T = 2，承诺依次为 [1/5, 1]、[−1, 6/5]。

**手工推导：**
1. **t=1 的上界。** 若 y₁ = −1，设备 1、2 不能充电（p₁, p₂ ≥ 0），所以设备 3、4 至少净吸收 1：p₃ + p₄ ≤ −1。因此 K₁ 上 e₃+e₄ ≤ E₃+E₄ − 1 = 1。
2. **t=1 的下界。** 若 y₁ = 6/5，设备 1、4 最多共放 D₁+D₄ = 1。所以 e₂+e₃ ≥ 1/5。
3. **t=1 的差。** 两式相减，K₁ 上 e₄ − e₂ ≤ 4/5。
4. **推回 t=0。** 第一步中 p₄ ≤ D₄ = 0，−p₂ ≤ C₂ = 0，所以 e₄ − e₂ 不会减小。因此 K₀ 上 e₄ − e₂ ≤ 4/5。
5. **外包里的点。** K₀ 的子集外包包含 e* = (4, 0, 1/5, 1)，其中 e₄ − e₂ = 1。

**精确证书（`evidence/n4_real_certificate.py`）：**
- 30 个子集方向各给出一个有理数端点树策略，逐一精确验证其可行性。它们说明 K₀ 的紧子集界至少这么宽，所以 e* 在外包内。这里只需要可行性，不需要这些值是精确最优。
- 第 4 步的不等式是初等有效不等式，e* 违反它。
- **它还是一个 facet**（复核补充，`review_codex_n4_geometry.py`）：用有理数原始—对偶证书精确算出 30 个子集支撑值和 max_{K₀}(e₄ − e₂) = 4/5；K₀ 满维（维数 4），在 e₄ − e₂ = 4/5 上取等号的面维数为 3。ε = 1/100 时同样成立（值为 17/20）。

**后果：** 用子集界递推判定，会接受初态 e* 下的这个承诺，但它其实不可兑现。

**不是零功率的退化现象：**
- 取 C = (1/100, 1/100, 3, ½)，D = (1, ½, 2, 1/100)，同样有精确证书：e* = (4, 0, 9/50, 1)，e₄ − e₂ = 1 > 17/20。
- 一般地，令 C₁ = C₂ = D₄ = ε：K₁ 上 e₃+e₄ ≤ 1 + 2ε，e₂+e₃ ≥ 1/5 − ε，所以下一状态的差 ≤ 4/5 + 3ε；第一步的动作最多再改变 2ε，所以 K₀ 上 e₄ − e₂ ≤ 4/5 + 5ε。ε = 1/100 时正好是 17/20。
- 浮点扫描显示，ε 增大到约 0.04 时间隙消失。

**推广到 N ≥ 5：** 加入 E = C = D = 0 的惰性设备，则 K_t 变为 K_t × {0}。点 (e*, 0) 仍在子集外包内、仍不可行。此时应把 facet 理解为仿射包内的相对 facet。

**机制：** 设备 3 同时出现在一个上界约束和一个下界约束里（相当于例 A 中的 M）。设备 2、4 几乎不能向相反方向调整，所以 t=1 的混号约束原样传回 t=0。子集和只记录同号组合，看不到这种耦合。N=3 时没有第四台设备来充当 R₀∖M，所以不会出现。

## 7. 对研究问题的含义与开放问题

1. **H3′ 在 N≥4 时不成立（第三层）。** 所以“固定 N 的子集界精确算法”只能在 N≤3 时成立；N≥4 时子集界递推只是外包，会误判接受。
2. **开放问题（暂时挂起；10-10 已否定）：** N≥4 时，真实 K_t 的法向量是否都在 {0,±1}ᴺ 内？
   - **10-10：** 否。N=4、T=4 的真实 K₀ 有法向量 (−1,0,0,2) 的面，精确证书 `evidence/n4_normal_certificate.py`。新的问题是系数是否随 T 增长，见 `N3_METHOD_AND_N4_PLAN_ZH.md` §4。
   - 命题 1 说明单请求步骤只产生 {0,±1} 法向量，但反复迭代并与盒取交后，是否会出现别的法向量（蓝图 §4.2 的 (2,1,1) 来自非 H3″ 输入）还不知道。
   - 若成立，3ᴺ 个方向的递推在固定 N 时仍关于 T 多项式。
   - 目前证据很弱：混号面本来就少见。
3. **文献定位（09-29 已做公式级核对，详见 `LITERATURE_CHECK_20260929_ZH.md`）：**
   - **工具引理：** 引理 3(a)(b) 由标准的分离定理加上坐标或总量约束直接得到，应当作工具引理，不算独立新意。准确的说法是“子模/超模 sandwich 描述与坐标或总量约束”，因为输入不要求交叉条件。
   - **可能的新结构结果：** 命题 1、引理 3(c)(d) 的三维闭式、定理 4，以及“N≤3 成立、N=4 失败”的分界。09-29 的检索没有找到先例；最近的背景是 Moriguchi–Murota 定理 4.1（L 凸集之和的 {0,±1} 描述）和 Danilov–Koshevoy（幺模性与 Minkowski 和），储能方向最近的邻居是 Evans–Tindemans–Angeli 2022（因果、有回充，但限定两阶段）。这仍只是“没找到”，Frank、Fujishige、Murota 三本书的全文还没有核对。
   - **已知的区分：** Moriguchi–Murota 2110.10445 §6.3 把连续 M♮₂ 多面体定义为两个 g-polymatroid 的交，描述函数取 max/min，不必保持超模/子模。所以不能从一般的 M♮₂ 框架直接推出 H3″。
