# N≥4 的上下界夹逼：外包有多接近精确，内近似有多保守

2026-10-07 起草，2026-10-09 按独立复核（`REVIEW_THEOREM_H_20261007_CODEX_ZH.md` §10）修订口径。回应两点担心：第 2 点“间隙可能可以用功率比控制”，第 3 点“外包误判的方向不安全，应与内近似配对”。

**性质：** 全部是浮点数值实验，只说明所测参数分布上的经验现象。它不是最坏情形的界，也不是证明，也不能作为一般误判率的上界或“停止收紧外包”的依据。

## 0. 结论

- **外包的经验误判很少。** 只看 N≥4（N=3 时外包由定理 4 保证精确，不应计入分母），在外包接受的抽样初态中：
  - 允许零功率时，实际兑现不了的有 **3/79,850**，集中在 2 个含单向设备的 N=6 实例；
  - 全部功率为正时为 **0/78,019**。
  - 这些点按实例成组抽取、彼此不独立，不能当作独立同分布样本给出普适的置信界。例 C 的正功率版本已经说明，外包在一般情形下不精确。
- **所实现的内近似很保守。** 固定参与因子策略能认证外包接受的初态中的 61%–76%，其余约四分之一到五分之二（24%–39%）需要精确判定，而它们几乎全部其实能兑现。
- **含义：** 在本次分布上，夹逼的宽度主要来自内近似。更好的内近似值得研究；这一结果不构成停止收紧外包的理由。

## 1. 实验设计

脚本：`evidence/sandwich_experiment.py`；汇总：`evidence/sandwich_summary.py`；原始数据在 `evidence/results_20261007/`。

- **实例：**
  - N = 3–6 台异构设备，T = 2–4 段。E 取 1–5 的整数。
  - C、D 有两种取法：从 {0, ½, 1, 2, 3} 取（允许单向设备），或从 {½, 1, 2, 3} 取（全部为正）。
  - 请求区间以随机中心、随机半宽生成。
  - 每种取法 4 个种子，各 1,500 个实例；外包非空并成功抽到样本的约 4,350 个实例。
- **三个判定：**
  - **外包：** 子集界递推（`oracle2.subset_recursion`）。N≤3 时由定理 4 保证精确，N≥4 时是外包。
  - **内近似：** 固定参与因子。设备 i 承担放电请求的 w⁺_i、充电请求的 w⁻_i，两组比例各自和为 1。对给定的初态和承诺，用一个 LP 判断是否存在这样的比例，使所有请求路径下功率和电量约束都满足。它是一个合法的因果策略，所以接受一定安全。脚本对每个样本都断言“内近似接受 ⟹ 精确可行”，从未触发。
  - **精确：** 端点请求树 LP。报不可行时关闭 presolve 重解，见 CLAUDE.md 的工作纪律。
- **抽样：** 每个实例在外包内做拒绝抽样，最多抽 4,000 次、最多保留 25 个点；一个点都没抽到的实例被丢弃。
  - 允许零功率时，有 206 个保留实例不足 25 个点；全部功率为正时有 242 个。
  - 对单个实例，这是外包内的均匀分布；合并各实例后，是按成功点数加权的经验分布，外包很细或低维的实例被低估。
  - 10-09 起，脚本把每个实例的输入（E、C、D、请求区间）和误判的初态都存进 JSON，便于以后对误判点补精确证书。
- **功率比：** ρ = min_i min(C_i, D_i) / max_i max(C_i, D_i)。有单向设备时 ρ = 0。

## 2. 结果

### 2.1 允许单向设备

| N | 实例 | 初态 | 误判接受 | 内近似接受 | 需要精确判定 |
|---|---:|---:|---:|---:|---:|
| 3 | 1,046 | 25,681 | 0 | 75.8% | 24.2% |
| 4 | 1,060 | 25,719 | 0 | 69.5% | 30.5% |
| 5 | 1,137 | 27,591 | 0 | 66.3% | 33.7% |
| 6 | 1,110 | 26,540 | 3（0.011%） | 63.4% | 36.6% |

3 个误判都出现在 ρ = 0 的实例里，即含有只能单向动作的设备（2 个实例，各为 N=6）。这两个实例的输入和误判初态在 `results_20261007/sandwich_with-zeros_3.json`（T=3，2 个点）和 `sandwich_with-zeros_4.json`（T=4，1 个点）里，还没有补精确证书。

### 2.2 全部功率为正

| N | 实例 | 初态 | 误判接受 | 内近似接受 | 需要精确判定 |
|---|---:|---:|---:|---:|---:|
| 3 | 1,121 | 27,513 | 0 | 71.0% | 29.0% |
| 4 | 1,062 | 25,743 | 0 | 65.0% | 35.0% |
| 5 | 1,086 | 26,058 | 0 | 64.0% | 36.0% |
| 6 | 1,100 | 26,218 | 0 | 60.8% | 39.2% |

按 ρ 分组时，所有 ρ > 0 的组误判都是 0；内近似的保守程度随 ρ 变化不大，主要随 N 增大而变差。

**汇总口径（复核核对）：**

| 参数族 | N=3–6：实例 / 初态 / 误判 | 只取 N≥4：实例 / 初态 / 误判 |
|---|---|---|
| 允许零功率 | 4,353 / 105,531 / 3 | 3,307 / 79,850 / 3 |
| 全部功率为正 | 4,369 / 105,532 / 0 | 3,248 / 78,019 / 0 |

## 3. 关于第 2 点：间隙上界

- **单步的界不小，而且只是约束的松弛。** 从定理 2 的证明看，对单个请求，混号约束的右端与子集外包推出的界之差不超过 g(M) ≤ min(w(M), w(R₀∖M))，其中 w = C + D，也就是 R₀ 中较小一侧设备的总功率。这只是相应单步混号约束的松弛上界，不是多步递推后集合之间的距离界。功率与容量往往是同一量级，所以它不能解释数值上看到的误判很少。
- **为什么少见。** 真实递推里，间隙需要 K_{t+1} 先有“上界子集和下界子集共享一个设备”的交叉结构，并且这个结构能原样传回前一段。在例 B、例 C 里，这要靠几乎只能单向动作的设备。这与本实验一致：误判只出现在 ρ = 0 的实例中。
- **建议：** 把“ρ 大于某个阈值时间隙为 0”或“间隙随 ρ 的界”作为猜想，暂不投入证明，除非 Yize 认为这个方向更重要。

## 4. 局限

- 实例是随机的，T ≤ 4，N ≤ 6。对抗性构造（例 B、例 C 那样的参数）下间隙可以到 0.5 量级，见 `N3_THEOREM_N4_COUNTEREXAMPLE_ZH.md` 和 `HOMOGENEOUS_FLEET_ZH.md`。
- 在外包内均匀抽样，会低估“间隙很薄但存在”的情形。
- 精确判定用的是浮点 LP，误判计数没有逐个给出有理数证书。若要在论文里报告具体数字，应对误判样本补精确证书（做法同 `n4_real_certificate.py`）；10-09 重跑后的 JSON 已保存了所需输入。
- 内近似“接受即安全”在数学上成立（它是合法的因果策略），但脚本里是浮点 LP 判断，status=0 不是有理数证书；对每个样本的“内近似接受 ⟹ 精确可行”断言也只是浮点交叉检查。
- 内近似只实现了参与因子这一种；Xie & Chen 的矩形内近似需要原文细节，这次没有复现。

## 5. 下一步建议

1. **更好的内近似。** 候选做法：
   - 把设备分成不超过 3 组，组内固定参与因子，组间用定理 4 的精确递推；
   - 只有一种型号时直接用定理 H；
   - 与 Xie & Chen 的矩形方法比较。
2. **对 N≥4 的实际用法。** 先用外包判定；外包接受而内近似拒绝的情形（本次约四分之一到五分之二），再交给精确的树 LP。由 §2 的比例估计计算量的节省。
